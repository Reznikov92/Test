Версия 3

git init - инициализировать гит в проекте
git add "название файла" - добавить файл для коммита
git commit -m "название коммита" - сделать коммит репозитория
git status - информация по рабочему проекту
git branch "название ветки" - создать новую ветку
git log - история коммитов
git checkout "название ветки или хэш коммита" - переместиться к коммиту/ветке
git merge "название ветки" - объединить две ветки
git push - отправить коммит на удаленный репозиторий
